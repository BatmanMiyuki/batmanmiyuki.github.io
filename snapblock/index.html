✅ App installée — vous êtes en mode application

Installer via le menu du navigateur :

🤖 Android (Chrome) : touchez le menu ⋮ en haut à droite → « Installer l'application » (ou « Ajouter à l'écran d'accueil »).

🍎 iPhone / iPad (Safari) : touchez le bouton Partager (carré avec flèche vers le haut) → « Sur l'écran d'accueil » → Ajouter.

💻 Ordinateur (Chrome / Edge) : cliquez sur l'icône d'installation dans la barre d'adresse, ou menu ⋮ → « Installer… ».

ℹ️ L'installation nécessite que cette page soit ouverte en HTTPS ou via localhost — un simple double-clic sur le fichier (file://) ne peut pas créer d'app.

    📲 Comment installer ce site comme une application (PWA) ?

    Utilisez le bouton « Installer l'app » en haut de la page. Cette PWA tient en un seul fichier : le manifest et les icônes sont générés directement dans le code, il n'y a ni manifest.json ni sw.js séparés.

    Condition imposée par les navigateurs : la page doit être servie en HTTPS (ou via localhost sur un ordinateur). Si vous ouvrez le fichier par double-clic (file://), le site fonctionne normalement, mais le navigateur ne proposera pas l'installation. Astuce : hébergez ce fichier unique sur un service gratuit (Netlify Drop, GitHub Pages, Cloudflare Pages…), ouvrez l'adresse obtenue sur votre téléphone, puis installez.

    Note technique : il n'y a pas de service worker (impossible à faire tenir dans un seul fichier — les navigateurs refusent les workers en blob:/data:). L'app installée ouvre donc la page en ligne ; mais une fois chargée, l'analyse de vos fichiers se fait entièrement hors-ligne, sur votre appareil.

    Je n'ai pas reçu l'e-mail de Snapchat, c'est normal ?

    Ça prend en général quelques minutes, parfois quelques heures. Vous pouvez aussi retourner dans Mes données → Voir les exports dans l'app (ou sur accounts.snapchat.com) : le bouton Télécharger apparaîtra là dès que c'est prêt. Pensez à vérifier vos spams.

    Le site envoie-t-il mon fichier quelque part ?

    Non. Tout se passe dans votre navigateur, sur votre appareil. Aucun serveur ne reçoit votre fichier, aucun compte à créer, et on ne vous demandera jamais votre mot de passe Snapchat. Si un site vous le demande : fuyez, c'est du phishing.

    Ça me dit qui m'a bloqué, moi ?

    Non — et aucun site ne peut le savoir de façon fiable : Snapchat ne communique cette information nulle part. Ici, on affiche uniquement les personnes que vous avez bloquées vous-même.

    « Aucune liste de bloqués trouvée », que faire ?

    Vérifiez que dans l'écran « Mes données » vous aviez bien activé « Exporter des fichiers JSON » et « Données utilisateur », puis refaites un export si besoin. Ouvrez aussi les « Détails techniques » ci-dessus : ils montrent les fichiers et clés détectés — ça aide à comprendre ce que contient votre export.
