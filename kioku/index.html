☁️ Activer le Cloud KIOKU

Pourquoi activer le Cloud ?
• Chaque compte aura ses animes sauvegardés dans le cloud (Firestore) → tu te connectes depuis n'importe quel téléphone/PC et tu retrouves tout
• Les amis fonctionnent entre appareils (plus besoin d'être sur le même appareil)
• Toujours single-file sur GitHub Pages, gratuit
  1. Va sur console.firebase.google.com → Créer un projet (nom: kioku, gratuit)
  2. Dans le projet : Créer une application Web (</>) → copie la config const firebaseConfig = {...}
  3. Active Authentication → Email/Password (activer)
  4. Active Firestore Database → Créer (mode test, pour commencer)
  5. Colle la config JSON ci-dessous :
Ta config est stockée en local (kioku.firebaseConfig) et ne quitte jamais ton navigateur sauf pour se connecter à Firebase. Tu peux la supprimer à tout moment dans Paramètres.
